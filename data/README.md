# Data directory

This folder contains the public/de-identified analysis inputs and generated processed datasets used by the LENS reproducibility workflow.

---

## Directory layout

```text
data/
├── raw_public/             # Public analysis inputs used by scripts and notebooks
├── processed/              # Processed files generated by the canonical R scripts
└── processed_notebooks/    # Processed files generated by notebook runs
```

The script pipeline writes to `data/processed/` by default. The notebook pipeline writes to `data/processed_notebooks/` so that reviewers can compare script and notebook outputs without overwriting either set.

---

## Raw public inputs

### `raw_public/student_course.csv`

Unit: one student-course observation.

Main fields:

| Field group | Variables | Description |
|---|---|---|
| Identifiers | `student_id`, `course_id`, `term`, `section_id`, `instructor_id` | De-identified identifiers used for joins and fixed effects |
| Redesign timing | `switch_term`, `post_redesign`, `redesign_status` | Indicates whether the observation belongs to a pre- or post-redesign course offering |
| Grade outcome | `final_numeric_grade`, `final_grade_letter_sampled` | Final numeric grade and sampled letter-grade check field |
| OLSE items | `q1_1`-`q1_8`, `q2_1`-`q2_5`, `q3_1`-`q3_6`, `q4_1`-`q4_5`, `q5_1`-`q5_6` | Thirty ordered OLSE survey item responses |
| OLSE summaries | `olse_q1_mean`, `olse_q2_mean`, `olse_q3_mean`, `olse_q4_mean`, `olse_q5_mean`, `olse_overall_mean`, `olse_overall_z` | Domain-level and overall OLSE means |

Expected row count: 1,568.

### `raw_public/course_term.csv`

Unit: one course-section-term offering row.

Main fields:

| Field group | Variables | Description |
|---|---|---|
| Identifiers | `course_id`, `term`, `section_id`, `instructor_id` | Course offering identifiers |
| Redesign timing | `switch_term`, `post_redesign`, `redesign_status` | Pre/post redesign status |
| Offering summaries | `enrollment_n`, `avg_numeric_grade`, `median_numeric_grade`, `mode_letter_grade`, `avg_olse_overall` | Section-term summaries |
| Redesign composites | `mastery_redesign`, `social_vicarious_redesign`, `structural_compliance_redesign`, `redesign_intensity` | Course-level redesign measures joined to course-term rows |
| Standardized composites | `*_z` fields | Standardized redesign composites |

Expected row count: 268.

### `raw_public/course_redesign.csv`

Unit: one course-level redesign record.

Main fields:

| Field group | Variables | Description |
|---|---|---|
| Course timing | `course_id`, `has_pre`, `has_post`, `pre_terms`, `post_terms`, `course_has_both_pre_and_post` | Course-level redesign timing diagnostics |
| Cluster scores | `cluster_1_pre_score` through `cluster_8_post_score` | Pre/post course-review scores for eight Legon-aligned clusters |
| Cluster deltas | `cluster_1_delta` through `cluster_8_delta` | Normalized pre/post score changes by cluster |
| Redesign composites | `mastery_redesign`, `social_vicarious_redesign`, `structural_compliance_redesign` | Theory-guided composites used in RQ1 and RQ3 |
| Overall intensity | `redesign_intensity` | Average normalized change across clusters |
| Standardized measures | `*_z` fields | Standardized redesign composite/intensity variables |
| Instructor summary | `instructor_ids` | De-identified instructor identifiers associated with course records |

Expected row count: 19.

## Processed files

The script `scripts/01_prepare_data.R` creates the processed analysis inputs:

| File | Used by | Description |
|---|---|---|
| `processed/student_term_fe_analysis.csv` | RQ1, RQ2, figures | Student-course analytic file with derived identifiers, grade z-scores, redesign composites, and post-redesign interactions |
| `processed/course_term_grade_aggregation.csv` | RQ1 robustness | Course-term aggregate grade and OLSE summaries |
| `processed/course_term_clean.csv` | Diagnostics and traceability | Cleaned course-section-term records |
| `processed/course_redesign_clean.csv` | RQ1/RQ3 redesign features | Course-level redesign features used by downstream models |
| `processed/input_validation_summary.csv` | Review/audit | Row counts and validation diagnostics |
| `processed/olse_scored_for_sem.csv` | RQ3 SEM | SEM-ready OLSE domain scores produced after measurement processing |

Notebook-generated equivalents are written to `processed_notebooks/`.

---

## Validation checks

The preparation script checks that the expected public release columns are present and that the analysis files match the expected analytic shape:

- 1,568 student-course observations.
- 19 courses.
- 268 section-term rows.
- 30 OLSE item columns.
- Required redesign composite fields.

If these checks fail, the pipeline stops before model estimation.

---

## Privacy note

The files in this folder are intended for aggregate reproducibility only. Do not attempt to identify students, instructors, sections, courses, or other institutional records. Do not use these data for individual-level prediction or automated decisions.
